# Pakonek Payment Portal

Customer payment reminder portal for Pakonek Fiber Internet.

## Files

- `index.html` — Main payment reminder webpage
- `.gitignore` — Git ignore rules

## Deploy with GitHub Pages

1. Create a new repository on GitHub, for example `pakonek-payment-portal`.
2. Upload `index.html` and `.gitignore`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish the site.

Your site will normally be available at:

`https://YOUR-GITHUB-USERNAME.github.io/pakonek-payment-portal/`

## Notes

The page uses externally hosted images from Imgur and links to Pakonek's payment portal, Facebook Messenger, and Google Maps.
